# LayoutIt!

Visual Bootstrap 5 interface builder for composing layouts, previewing markup, and exporting HTML or React code.

Use it at [build.layoutit.com](https://build.layoutit.com).

<img width="1826" height="1022" alt="LayoutIt! interface builder preview" src="https://build.layoutit.com/social.png" />

## What it does

LayoutIt! lets you build Bootstrap layouts visually: drag grid rows, columns, and components onto the canvas, edit content and classes, preview the result, then export clean HTML or a React project.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
